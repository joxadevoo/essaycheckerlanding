# IELTS Essay Checker — Rasmiy Landing Sahifasi 🚀

IELTS Task 2 insholarini sun'iy intellekt (AI) yordamida rasmiy British Council va Cambridge mezonlari asosida soniyalar ichida tekshiruvchi zamonaviy veb-sahifa.

## 🌟 Asosiy Xususiyatlar

- **Jonli IELTS Sinov Boxi:** Foydalanuvchilar o'z insholarini bevosita saytda yozib, real vaqtda so'zlar sonini hisoblash va band ballarini hisoblash imkoniyati.
- **Rasmiy Mezonlar:** Task Response (TR), Coherence & Cohesion (CC), Lexical Resource (LR), Grammatical Range & Accuracy (GRA) bo'yicha to'liq tahlil.
- **Premium Dizayn:** Glassmorphism, jonli animatsiyalar, to'liq responsiv (mobil, planshet va kompyuterga mos).
- **Tezkor Integratsiya:** Telegram botga (@esseycheckerbot) to'g'ridan-to'g'ri bog'lanish va guruhlarga qo'shish tugmalari.

## 🛠 Texnologiyalar

- **HTML5 & Vanilla CSS3** (zamonaviy grid, flexbox, CSS o'zgaruvchilari)
- **Vanilla JavaScript (ES6+)**
